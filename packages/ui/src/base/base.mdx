# Base stylesheet

The stylesheet that makes plain HTML look right on day one: a small reset, body text in the `type-body-md` role, the focus ring, the selection highlight, size-keyword transitions (`interpolate-size`), a stable scrollbar gutter and balanced or pretty text wrapping. Everything sits in the `ab.reset` and `ab.base` cascade layers, so components and any unlayered app CSS win over it.

`Provider` (`@platform/ui/provider`) brings it, after the layer order, the tokens and the fonts. Apps import no CSS themselves.
