# Internationalization

The library ships no interface text. You write every label, and formatting follows the language you set.

## Set the language and direction once

Give `UIProvider` the same language as `<html lang>`, and set `dir` for right-to-left languages:

```tsx
// app/[lang]/layout.tsx
import { getDirection } from "@abereghici/ui/direction";
import { UIProvider } from "@abereghici/ui/ui-provider";

export default async function RootLayout({ children, params }: LayoutProps<"/[lang]">) {
  const { lang } = await params;

  return (
    <html lang={lang} dir={getDirection(lang)}>
      <body>
        <UIProvider locale={lang}>{children}</UIProvider>
      </body>
    </html>
  );
}
```

| What                                   | Follows                                     |
| -------------------------------------- | ------------------------------------------- |
| Month and weekday names, date segments | `locale`, through `Intl`                    |
| Numbers and percentages                | `locale`, through `Intl`                    |
| Typing to jump in lists                | `locale`, through `Intl`                    |
| Layout direction                       | `dir`; `getDirection` reads it from the tag |

The server and the browser then format alike, so hydration matches. Dates are Gregorian in every language.

## Write the text

Pass text as `children` or as a named prop. Where a control would otherwise have no name, TypeScript requires the text:

```tsx
<Dialog.Close aria-label={t("close")} />
<NumberField label={t("seats")} incrementLabel={t("increase")} decrementLabel={t("decrease")} />
<Toaster aria-label={t("notifications")} closeLabel={t("dismiss")} />
<Spinner>{t("loading")}</Spinner>
```

## Right-to-left

Set `dir="rtl"` on `<html>`, or on one region, and every component mirrors.

- **Icons in labels** stay in source order, so they keep their place in either direction.
- **Icons that don't mirror:** the Logo, and glyphs of physical things, such as a clock or a check.
- **Your own CSS** should use logical properties (`padding-inline`, `inset-inline-start`), so it mirrors too.
