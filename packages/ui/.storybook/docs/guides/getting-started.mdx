# Getting started

Three steps: install the package, wrap the app in `UIProvider`, import components one at a time.

## Requirements

| Requirement     | Version                                                                 |
| --------------- | ----------------------------------------------------------------------- |
| React           | 19.2 or later                                                           |
| Browser targets | [Baseline newly available](https://web.dev/baseline), with no polyfills |

## 1. Install

```sh
pnpm add @abereghici/ui
```

`@abereghici/tokens` comes with it. Then set the app's browser targets in `package.json`:

```json
{
  "browserslist": ["baseline newly available"]
}
```

Without this, Next.js lowers `light-dark()` for older browsers and `data-theme` regions stop switching.

## 2. Add the provider

Render `UIProvider` once, at the root. It brings the tokens, fonts and base styles, so the app imports no CSS from the design system.

```tsx
// app/layout.tsx
import { UIProvider } from "@abereghici/ui/ui-provider";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en-US">
      <body>
        <UIProvider locale="en-US">{children}</UIProvider>
      </body>
    </html>
  );
}
```

Give `locale` the same value as `<html lang>`, so dates and numbers match between server and browser.

## 3. Use a component

Each component has its own entry point and brings only its own JavaScript, CSS and tokens.

```tsx
import { Button } from "@abereghici/ui/button";
import { PlusIcon } from "@abereghici/ui/icons/plus";

<Button variant="primary">
  <PlusIcon />
  New project
</Button>;
```

Compound components are namespaces: `import { Card } from "@abereghici/ui/card"`, then `<Card.Root>` and `<Card.Title>`.

## Next.js

- **Server Components.** Static components render on the server; interactive ones are client components and need no `"use client"` from you.
- **CSS per route.** Next.js merges small stylesheets into shared chunks, so a route can load CSS for components it never imports. For strictly per-route CSS, set `cssChunking: { type: "graph", requestCost: 0 }` ([docs](https://nextjs.org/docs/app/api-reference/config/next-config-js/cssChunking)), at the cost of more requests.
