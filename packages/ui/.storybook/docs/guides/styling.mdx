# Styling

Restyle with tokens first and CSS second. Your CSS always wins over the design system, without `!important`.

## Choose the right tool

| You want to…                                | Do this                                                    |
| ------------------------------------------- | ---------------------------------------------------------- |
| Change one component everywhere             | Set its component tokens on `:root`                        |
| Change one component in one region          | Set its component tokens on that region                    |
| Change one instance                         | Pass a `className`; every component merges it with its own |
| Style your own elements                     | Use semantic tokens, never primitives                      |
| Change a base style, such as the focus ring | Write unlayered CSS                                        |

To find a component's tokens, filter the [token explorer](?path=/docs/reference-tokens--docs) by component.

## Component tokens

```css
:root {
  --ab-button-primary-background-color: var(--ab-color-background-success-bold);
}
```

## Your own elements

```css
.callout {
  padding: var(--ab-space-inset-md);
  border-radius: var(--ab-radius-lg);
  background: var(--ab-color-surface-raised);
  color: var(--ab-color-text-default);
  font: var(--ab-type-body-md);
  letter-spacing: var(--ab-type-body-md-letter-spacing);
}
```

The `font` shorthand can't carry letter spacing, so a type role takes at least two declarations; `data` roles add `font-variant-numeric`, and `overline` roles add `text-transform`.

## Why your CSS wins

The design system puts all of its CSS in cascade layers:

```css
@layer ab.reset, ab.tokens, ab.base, ab.components;
```

CSS outside any layer beats every layer, whatever its specificity or order.

```css
/* Unlayered, so it wins over ab.base. */
:focus-visible {
  outline-color: var(--ab-color-border-accent);
}
```

## Base styles

`UIProvider` brings a small base stylesheet in `ab.reset` and `ab.base`: a reset, body text in the `body-md` role, the focus ring, selection color, a stable scrollbar gutter, and balanced headings. Components and your CSS override it.
