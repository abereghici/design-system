# Bereghici Design System

React components, design tokens, type and iconography for Alexandru Bereghici's products. Every component is built on native HTML, styled from a three-tier token set, and meets WCAG 2.2 Level AA in both Themes.

- **Packages:** `@platform/ui` (components, icons, locales) and `@platform/tokens` (CSS custom properties, fonts).
- **Themes:** System, Light and Dark. The tokens also adapt to increased contrast, reduced transparency, reduced motion and forced colors.
- **Platform:** Baseline newly available. Native elements and CSS first; script adds only what the platform can't.
- **Status:** Unreleased. Components ship phase by phase, and a component appears here once it is built.
