## Principles

- **Accessible by default.** Color pairings are checked for WCAG AA contrast when the tokens build, and every story is checked with axe in CI.
- **Platform first.** Native elements and CSS before script.
- **Semantic tokens.** Code names an intent, such as `--ab-color-text-subtle`, never a raw value.
- **Quiet surfaces.** Surfaces stay neutral; color marks an action, a state or a highlight.
- **Flat in the flow, lifted above it.** Content separates with space and hairlines; shadows mark what you can press and what floats above the page.
- **Pay for what you use.** Importing a component brings its own code, CSS and tokens, and those of the components it uses.
