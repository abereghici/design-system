## Packages

| Package              | Contains                                                                     |
| -------------------- | ---------------------------------------------------------------------------- |
| `@abereghici/ui`     | React components, one entry point each, and icons                            |
| `@abereghici/tokens` | Design tokens as CSS custom properties, and the Figtree and Noto Serif fonts |

## Principles

- **Accessible by default.** Every color pairing the tokens allow meets AA, every control works from the keyboard, and the user's contrast, motion and transparency settings are honoured.
- **Platform first.** Native elements and CSS do the work, so components behave the way the browser does.
- **Semantic tokens.** Code names an intent, such as `--ab-color-text-subtle`, never a raw value.
- **Quiet surfaces.** Surfaces stay neutral; color marks an action, a state, or the one highlight on a page.
- **Flat in the flow, lifted above it.** Content separates with space and hairlines; shadows mark what you can press and what floats above the page.
- **Pay for what you use.** Importing a component brings only its JavaScript, CSS and tokens.
