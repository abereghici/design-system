# Motion

Fast, eased out, interruptible and optional. Motion confirms what the user did and shows where things come from; it never decorates.

## Choosing a duration and easing

| Moment                       | Duration                            | Easing                 |
| ---------------------------- | ----------------------------------- | ---------------------- |
| Press feedback               | `motion-duration-press`, 100ms      | `motion-easing-enter`  |
| Hover color                  | `hover-in` 120ms, `hover-out` 250ms | `motion-easing-color`  |
| Checkbox, radio or switch    | `motion-duration-toggle`, 180ms     | `motion-easing-enter`  |
| Menu or popover opens        | `motion-duration-popover`, 200ms    | `motion-easing-enter`  |
| Panel expands                | `motion-duration-expand`, 250ms     | `motion-easing-move`   |
| Dialog opens                 | `motion-duration-modal`, 250ms      | `motion-easing-enter`  |
| Sheet slides in              | `motion-duration-drawer`, 300ms     | `motion-easing-drawer` |
| Selection settles into place | `motion-duration-spring`, 400ms     | `motion-easing-spring` |
| Anything leaves              | `motion-duration-exit`, 150ms       | `motion-easing-exit`   |

Every duration and easing, with what it is for, is in the [token explorer](?path=/docs/reference-tokens--docs) under Motion.

## Rules

- **Ease out** to enter and to leave; exits are faster than entrances.
- **Grow from the trigger,** never from nothing. Dialogs stay centred.
- **Reverse from where it is** when triggered again mid-way.
- **Springs only** for a selection settling into place (switch thumb, radio dot, tab and segmented-control indicators) and a toast arriving.

## Reduced motion

With reduced motion on, the tokens remove movement: scales, distances and blurs become neutral and stagger becomes 0, while fades and color changes stay. Components read the tokens, so apps get this with no code.

<Guidance>
<Do>

- Use the motion tokens for anything you animate, so reduced motion applies to it too.
- Keep loading indicators as the only things that loop.

</Do>
<Dont>

- Animate keyboard-initiated or very frequent actions.
- Use ease-in; it feels slow to start.
- Hard-code durations.

</Dont>
</Guidance>
