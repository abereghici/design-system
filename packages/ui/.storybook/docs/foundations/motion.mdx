# Motion

Fast, eased out, interruptible and optional. Motion confirms what the user did and shows where things come from; it never decorates.

## Durations

<TokenRows match="^ab-motion-(duration|delay)-" />

## Easings

<TokenRows match="^ab-motion-easing-" />

## Rules

- **Ease out** to enter and to leave.
- **Grow from the trigger,** never from nothing. Dialogs stay centred.
- **Reverse from where it is** when triggered again mid-way.
- **Springs only** for a selection settling into place (switch thumb, radio dot, tab and segmented-control indicators) and a toast arriving.

## Reduced motion

With reduced motion on, these tokens change: <Changes when="(prefers-reduced-motion: reduce)" />. Scales, distances and blurs become neutral, while fades and color changes stay. Components read the tokens, so apps get this with no code.

<Guidance>
<Do>

- Use the motion tokens for anything you animate, so reduced motion applies to it too.
- Keep loading indicators as the only things that loop.

</Do>
<Dont>

- Animate keyboard-initiated or very frequent actions.
- Use ease-in; it feels slow to start.
- Hard-code durations.

</Dont>
</Guidance>
