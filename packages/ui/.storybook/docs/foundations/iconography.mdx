# Iconography

A custom set on a 24-unit grid, drawn with straight strokes and square ends. Icons take the color of the text they sit in.

```tsx
import { BellIcon } from "@abereghici/ui/icons/bell";

<BellIcon size="md" />;
```

Browse and copy imports in the [icon explorer](?path=/docs/reference-icons--docs).

## Sizes

| Size | Pixels |
| ---- | ------ |
| `sm` | 16px   |
| `md` | 20px   |
| `lg` | 24px   |
| `xl` | 32px   |

Match the size to the text beside it; `md` is the default. The stroke changes with the size, so lines look equally heavy at every size.

## Meaning

- **Decorative by default.** An icon beside text is hidden from assistive technology.
- **Give it a `label`** only when it stands alone and carries meaning.
- **Icon-only buttons:** use `IconButton`, which requires a name and has a large enough target.

<Guidance>
<Do>

- Pair icons with a visible text label wherever there is room.
- Keep an icon's meaning the same everywhere it appears.

</Do>
<Dont>

- Use an icon on its own for an action people need to understand at a glance.
- Recolor parts of an icon; set `color` on the icon or its parent.

</Dont>
</Guidance>

## Custom icons

Pass your own paths to `Icon` to match the set: a 24 × 24 viewBox, straight lines, no curves or circles, square ends.

```tsx
import { Icon } from "@abereghici/ui/icon";

<Icon>
  <path d="M4 12h16" />
</Icon>;
```
