# Iconography

A custom set on a 24-unit grid: straight strokes only, with no curves or circles, and square ends, stroked in `currentColor` so an icon takes the color of the text it sits in.

```tsx
import { BellIcon } from "@abereghici/ui/icons/bell";

<BellIcon size="md" />;
```

- **Size and stroke go together,** so lines look equally heavy at every size; match the size to the text beside the icon.
- **An icon is decorative by default** and hidden from assistive technology. Name it only when it stands alone and carries meaning (`label`), and prefer a visible text label.
- **Icon-only controls** need a name and a large enough target; use IconButton, which handles both.
