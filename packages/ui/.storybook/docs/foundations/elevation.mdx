export const semantic = (family, prefix = "") =>
  tokens[family].tokens.filter(
    ({ name }) => name.startsWith(`ab-${prefix}`) && !/-\d+$/v.test(name),
  );

# Elevation

Content in the flow of the page stays flat and separates with space, hairlines and surface steps. Only floating layers are lifted.

## Elevations

Each Elevation separates the layer from any background in both Themes, with soft shadows that read warm rather than grey.

<TokenTable
  tokens={semantic("shadow")}
  preview={(value) => ({ boxShadow: value, borderRadius: "var(--ab-radius-md)" })}
/>

## Materials

Translucent fills with a backdrop blur, for floating chrome above content such as menus and the command palette. Never use them for content in the flow, or under long text. Under `prefers-reduced-transparency: reduce` every material becomes the solid floating surface.

<TokenTable
  tokens={[
    ...semantic("blur", "material-"),
    ...semantic("saturate", "material-"),
    ...semantic("opacity", "opacity-disabled"),
  ]}
/>

## Layering

The stacking order, lowest to highest. Floating layers that use the top layer (`popover`, `<dialog>`) need none of these.
