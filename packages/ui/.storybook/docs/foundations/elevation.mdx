# Elevation

Content in the page stays flat. Shadows are for things you can press and things that float above the page.

## Levels

<ElevationScale />

Each level is a hairline ring plus soft shadows tinted with Moss in light and Night in dark. In dark, a faint inner highlight sits on the top edge.

## Materials

Translucent fills with a backdrop blur, for overlay chrome such as menus and the command palette. Use a `color-material-*` fill with its matching `material-blur-*`. With reduced transparency, every material becomes solid.

## Layering

Popovers and dialogs use the browser's top layer and need no `z-index`. For anything else, use the `z-index-*` tokens, which keep a fixed order from `base` to `tooltip`.

<Guidance>
<Do>

- Separate in-page content with space, hairlines and surfaces.
- Use the level of the component you are building: `overlay` for a custom menu, `modal` for a custom dialog.

</Do>
<Dont>

- Put a shadow on static content, such as a card that is not a link.
- Put long text on a material.
- Invent a `z-index` value.

</Dont>
</Guidance>
