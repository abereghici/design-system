export const semantic = (family, prefix = "") =>
  tokens[family].tokens.filter(
    ({ name }) => name.startsWith(`ab-${prefix}`) && !/-\d+$/v.test(name),
  );

# Elevation

Content in the flow of the page stays flat and separates with space, hairlines and surface steps. Controls (Button, the fields, the Switch and Slider thumbs, the SegmentedControl indicator) and a hovered linked Card take `raised`; overlays take the rest.

## Elevations

Each Elevation is a hairline ring, an inner highlight in the dark Theme, and soft shadows tinted with Moss (light) or Night (dark) rather than neutral grey.

  tokens={semantic("shadow")}

/>

## Materials

Translucent fills with a backdrop blur, for overlay chrome above content such as menus and the command palette. Never use them for content in the flow, or under long text. Under `prefers-reduced-transparency: reduce` every material becomes the solid overlay surface.

<TokenTable
  tokens={[

    ...semantic("saturate", "material-"),
    ...semantic("opacity", "opacity-disabled"),
  ]}
/>

## Layering

The stacking order, lowest to highest. Overlays that use the top layer (`popover`, `<dialog>`) need none of these.
