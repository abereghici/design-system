# Color

Surfaces stay neutral. Color marks an action, a state, or the one highlight on a page. Light and dark are designed separately, not inverted.

## Surfaces

Pages are built from four surfaces, each sitting on the one before it. Overlays also cast a shadow.

<Surfaces />

| Surface   | Use for                                        |
| --------- | ---------------------------------------------- |
| `default` | The page                                       |
| `raised`  | A panel on the page, such as a sidebar or card |
| `nested`  | A panel inside a raised panel                  |
| `overlay` | Menus, popovers and dialogs                    |

## Roles

Pick the token by the property you are setting (`background`, `text`, `icon`, `border`), then the role.

| Role        | Use for                                     | Example tokens                                  |
| ----------- | ------------------------------------------- | ----------------------------------------------- |
| Neutral     | Most text, icons and borders                | `text-default`, `text-subtle`, `border-default` |
| `accent`    | The primary action, links, checked controls | `background-accent-bold`, `text-accent`         |
| `selected`  | The current item in a set                   | `background-selected`, `text-selected`          |
| `success`   | Completed, valid, positive                  | `background-success-subtle`, `text-success`     |
| `warning`   | Needs attention, may cause problems         | `background-warning-subtle`, `text-warning`     |
| `danger`    | Errors, destructive actions                 | `background-danger-bold`, `border-danger`       |
| `highlight` | The one marked phrase on a page             | `background-highlight`, `text-on-highlight`     |

## Pairing text with fills

| On this fill                                                     | Use                                                                    |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Any surface, `background-selected` or `background-accent-subtle` | Any text, icon or border role, except `*-disabled` and `border-subtle` |
| `background-{success, warning, danger}-subtle`                   | `text-default`, `text-subtle` or that role's text                      |
| `background-{accent, success, warning, danger}-bold`             | `text-on-{role}`                                                       |
| `background-highlight`                                           | `text-on-highlight`                                                    |
| `background-neutral-bold`                                        | `text-inverse`                                                         |

The token build fails if any of these pairs drops below WCAG AA in either Theme. [Accessibility](?path=/docs/foundations-accessibility--docs) lists the measured contrast.

<Guidance>
<Do>

- Keep to one primary button per view.
- Pair a status color with a label or an icon.
- Use `border-default` for any edge a control needs to be seen.

</Do>
<Dont>

- Use a palette step (`--ab-palette-*`) in product code.
- Use a text token as a fill, or a fill as text.
- Use brand colors (`color-brand-*`) for interface roles; they are for the Logo, imagery and print.

</Dont>
</Guidance>
