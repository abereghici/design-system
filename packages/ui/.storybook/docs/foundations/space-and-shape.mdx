export const semantic = (family, prefix = "") =>
  tokens[family].tokens.filter(
    ({ name }) => name.startsWith(`ab-${prefix}`) && !/-\d+$/v.test(name),
  );

# Space and shape

The system is compact with a mouse. On touch screens the same size tokens grow, so no component needs a touch variant.

## Space

`inline` is a horizontal gap, `inset` is padding, `stack` is a vertical gap, and `section` separates page sections.

<TokenTable
  tokens={semantic("spacing", "space-")}
  preview={(value) => ({ inlineSize: value, blockSize: "0.5rem" })}
/>

## Size

Icons, controls, containers and targets. `size-target-min` is the WCAG 2.5.8 minimum and `size-target-recommended` the comfortable touch target.

<TokenTable tokens={semantic("size", "size-")} />

## Radius

Nested corners share a centre: the inner radius is the outer radius minus the padding between them. Pick the token pair that satisfies the equation, never one that looks close.

<TokenTable tokens={semantic("radius", "radius-")} preview={(value) => ({ borderRadius: value })} />

## Layout

CSS can't read a custom property in a media query, so write the breakpoint's value from this table, as in `@media (width < …)`.
