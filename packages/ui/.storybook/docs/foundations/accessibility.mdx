# Accessibility

Every component targets **WCAG 2.2 Level AA** in both Themes. Most of it is built in; this page lists what is, and what you still provide.

## What you provide

- **Names.** A visible label for every field, and text for every icon-only control. TypeScript requires the ones a component can't work without.
- **Headings.** One `h1` per page, and levels in order.
- **Errors that say how to fix them,** passed as `errorMessage`.
- **An explanation** next to anything disabled.
- **Language.** `lang` on `<html>`, and `dir` for right-to-left.

## What is built in

| WCAG criterion                            | How                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------- |
| 1.4.3 Contrast (Minimum)                  | Every text role is at least 4.5:1 on every background it may sit on |
| 1.4.11 Non-text Contrast                  | Icons and control borders are at least 3:1                          |
| 1.4.1 Use of Color                        | A state pairs color with a label, a shape, a weight or an underline |
| 1.4.4 Resize Text                         | Text follows the reader's text size                                 |
| 1.4.10, 1.4.12 Reflow, Text Spacing       | Layouts reflow, and no text has a fixed height                      |
| 2.4.7, 2.4.11 Focus Visible, Not Obscured | One focus ring on every focusable component, never removed          |
| 2.5.8 Target Size (Minimum)               | Every target meets the minimum, and grows on touch screens          |
| 2.2.2 Pause, Stop, Hide                   | Only loading indicators loop: Spinner, Progress and Skeleton        |
| 2.3.3 Animation from Interactions (AAA)   | Reduced motion removes movement; the loading loops become fades     |

## Focus

Tab to the button. The ring is the same on every focusable component.

## Contrast

Every foreground on every background it may sit on, in the tokens' own colors, with the measured ratio. The token build fails if any of them drops below its minimum. `border-subtle` is decorative and never a control's only edge, and `disabled` roles are exempt, so neither is shown.

## Testing

Every story runs axe in the test suite, and a violation fails CI. The **Accessibility** panel under each story shows the same checks.
