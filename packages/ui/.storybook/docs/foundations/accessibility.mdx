# Accessibility

Components target **WCAG 2.2 Level AA** in both Themes. This page lists what the system guarantees, and what you provide.

## What you provide

- **Names.** A visible label for every field, and text for every icon-only control. TypeScript requires the ones a component can't work without.
- **Headings.** One `h1` per page, and levels in order.
- **Errors that say how to fix them,** passed as `errorMessage`.
- **An explanation** next to anything disabled.
- **Language.** `lang` on `<html>`, and `dir` for right-to-left.

## What is built in

| WCAG criterion                          | How the system meets it                                                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 1.4.3 Contrast (Minimum)                | Every text role is at least 4.5:1 on every background it may sit on; the token build fails otherwise                                      |
| 1.4.11 Non-text Contrast                | Every icon and control-border role is at least 3:1; the token build fails otherwise                                                       |
| 1.4.4 Resize Text                       | Font sizes are in `rem`, so text follows the reader's text size                                                                           |
| 2.4.7 Focus Visible                     | The base styles draw a focus ring on every `:focus-visible` element                                                                       |
| 2.5.8 Target Size (Minimum)             | The smallest control is <Value of="size-control-xs" />, the minimum of <Value of="size-target-min" />, and controls grow on touch screens |
| 2.2.2 Pause, Stop, Hide                 | Only Spinner, Progress and Skeleton loop                                                                                                  |
| 2.3.3 Animation from Interactions (AAA) | Reduced motion removes movement; see [Motion](?path=/docs/foundations-motion--docs)                                                       |

## Contrast

Every foreground on every background it may sit on, in the tokens' own colors, with the measured ratio. The token build fails if any of them drops below its minimum. `border-subtle` is decorative and never a control's only edge, and `disabled` roles are exempt, so neither is shown.

## Testing

Every story runs axe in the test suite, and a violation fails CI. The **Accessibility** panel under each story shows the same checks.
