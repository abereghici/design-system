# Security policy

## Supported versions

Security fixes go into the latest published version of `@abereghici/ui` and `@abereghici/tokens`.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/abereghici/design-system/security/advisories/new), not in a public issue.

Every version from 0.1.1 on is published from GitHub Actions through npm trusted publishing and carries a provenance attestation, which links it to the commit and workflow run that built it.
