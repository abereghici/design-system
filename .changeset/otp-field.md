Add OTPField (`@abereghici/ui/otp-field`): a one-time code in one input (`autocomplete="one-time-code"`, `inputmode="numeric"`, a `pattern` and `maxlength` from `length`, 6 by default), drawn as a box per digit in CSS. Paste and SMS autofill fill the whole code, screen readers hear one labelled field with its description and error, and its form submits the code with JavaScript off. The caret stays in the boxes: after the last digit, the last box draws it.
