Add SearchField (`@abereghici/ui/search-field`): a native `type="search"` input with the Search Enter key, its Field's label, description and validation, and a clear button named by `clearLabel` that replaces the browser's own. The clear button and Escape empty the field as a change request (`clear-press`, `escape-key`) and keep focus in it. With JavaScript off, its form still submits the text; the clear button is hidden.
